# Documentation and inline help

Users can open Documentation from the main navigation without a box or GitHub connection. The guide covers creating/importing boxes, opening and copying items, security keys and labels, GitHub backups and tokens, and recovery.

Contextual question-mark buttons open concise, accessible help dialogs. Each dialog has a title, Close button, Escape support, focus restoration, and a link to the corresponding documentation section. Opening or closing help preserves partially completed forms and unlocked boxes.

Settings includes an inline-help checkbox, enabled by default and remembered in this browser. Disabling it hides all contextual help controls; Documentation remains available. Toggling it does not clear other settings fields. Storage failures leave the app usable and clearly report that the setting applies only until reload.

Acceptance: Chrome verifies documentation navigation/deep links, dialog keyboard interaction and dismissal, persisted enabled/disabled states, blocked storage, preserved form values, and 320px layouts in both themes. Existing crypto, WebAuthn, and sync flows continue to pass.
